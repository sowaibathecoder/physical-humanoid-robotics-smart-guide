# Course Introduction

Welcome to the **Mastering Physical AI & Humanoid Robotics** course - a comprehensive 13-week hands-on capstone course designed to teach you how to build fully autonomous humanoid robots that accept voice commands, understand intent, plan, navigate, and manipulate objects. This course includes ≥ 120 verifiable citations with 70%+ being peer-reviewed or official NVIDIA/ROS documentation and is structured as a living Docusaurus book deployed via GitHub Pages.

## Comprehensive Course Overview

This intensive 13-week capstone program is structured into 4 progressive parts that take you from foundational concepts to advanced humanoid robotics capabilities:

### Part 1: Foundations of Physical AI (Weeks 1-2)
Master the fundamentals of physical AI and the robotic nervous system with ROS 2, the industry-standard middleware that connects all robotic systems. You'll learn about nodes, topics, services, URDF/XACRO modeling, and launch systems that form the backbone of all modern robotics applications.

### Part 2: The ROS Nervous System (Weeks 3-5)
Deepen your understanding of ROS 2 concepts including advanced node communication, parameter management, and system architecture. Focus on creating robust robotic systems with proper error handling and real-time performance.

### Part 3: Digital Twins & Simulation AI Robot Brain (Weeks 6-10)
Create sophisticated simulation environments and develop the AI brain for your robot. Learn to develop accurate virtual representations of real-world robots and environments, enabling safe testing and validation before physical deployment. Master perception processing and path planning for autonomous navigation in complex environments.

### Part 4: Vision-Language-Action (VLA) Humanoid Systems (Weeks 11-13)
Integrate cutting-edge AI models for end-to-end vision-language-action capabilities. Complete your capstone project building a fully autonomous humanoid that responds to voice commands and performs complex manipulation tasks using advanced AI models.

## Learning Objectives

By the end of this course, you will be able to:

- Design and implement ROS 2 workspaces for humanoid robotics applications
- Create digital twins using simulation environments
- Integrate AI models for vision-language-action tasks
- Deploy solutions to real hardware (Unitree G1 or equivalent)
