# Course Introduction

Welcome to the **Mastering Physical AI & Humanoid Robotics** course - a comprehensive 13-week hands-on capstone course designed to teach you how to build fully autonomous humanoid robots that accept voice commands, understand intent, plan, navigate, and manipulate objects.

## Course Overview

This course is structured into 4 modules across 13 weeks:

- **Module 1: The Robotic Nervous System (5 weeks)** - Master ROS 2, the industry-standard middleware that connects everything
- **Module 2: The Digital Twin (2 weeks)** - Simulation environments with Gazebo Ignition and Unity ROS TCP Connector
- **Module 3: The AI-Robot Brain (3 weeks)** - NVIDIA Isaac Sim, Isaac ROS GEMs, and Navigation2 SMAC Planner
- **Module 4: Vision-Language-Action Models (3 weeks)** - OpenVLA, RT-2X, Octo, and final capstone project

## Learning Objectives

By the end of this course, you will be able to:

- Design and implement ROS 2 workspaces for humanoid robotics applications
- Create digital twins using Gazebo Ignition and NVIDIA Isaac Sim
- Integrate AI models for vision-language-action tasks
- Deploy solutions to real hardware (Unitree G1 or equivalent)

## Hardware Requirements

The course is designed to work with a hardware budget of under $800:

- **Primary**: Jetson Orin Nano Super Kit
- **Alternative**: Ubuntu 22.04 + RTX 4070 Ti for simulation
- **Cloud Option**: AWS g5/g6 instances documented

## Course Structure

Each week includes:

- Theoretical foundations with peer-reviewed citations
- Hands-on lab exercises with GitHub templates
- Assessments to verify understanding
- Additional resources for deeper learning
